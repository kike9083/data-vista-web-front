Centro de Ayuda

Preguntas Frecuentes

¿Cómo buscar registros?

Utiliza la barra de búsqueda en la parte superior de la página. Puedes buscar por cualquier texto contenido en los registros.

¿Cómo exportar datos?

Haz clic en un registro para ver sus detalles y luego usa el botón "Exportar CSV" para descargar ese registro específico.

¿Cómo cambiar entre vista de tabla y tarjetas?

Utiliza los botones de "Tabla" y "Tarjetas" en la parte superior del panel de registros para cambiar el modo de visualización.

¿La aplicación es segura?

Sí, DataVista utiliza un proxy PHP para proteger tu token API. Los datos se transmiten de forma segura entre tu servidor y NocoDB.

Guía Rápida

Visualización de Datos

  • La vista de tabla muestra múltiples columnas
  • La vista de tarjetas es ideal para dispositivos móviles
  • Haz clic en cualquier registro para ver todos sus detalles

Navegación

  • Usa la paginación para navegar entre páginas de resultados
  • El menú superior permite acceder a las distintas secciones
  • En dispositivos móviles, usa el menú hamburguesa

Si necesitas ayuda adicional o encuentras algún problema, contacta al administrador del sistema.
