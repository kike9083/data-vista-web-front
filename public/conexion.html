Configuración de Conexión

Sigue estas instrucciones para conectar DataVista a tu API de NocoDB:

  1. Accede a tu panel de NocoDB en https://n8n-nocodb.kbma6o.easypanel.host/dashboard
  2. En el menú lateral, haz clic en tu cuenta y luego en "Tokens"
  3. Genera un nuevo token de API con permisos de lectura
  4. Copia el token generado
  5. Abre el archivo /api/data.php en tu servidor
  6. Reemplaza AQUI_TU_TOKEN_API con el token que copiaste
  7. Guarda el archivo

Por seguridad, nunca compartas tu token API. El archivo data.php funciona como un proxy para proteger tus credenciales.

Configuración avanzada

Si necesitas personalizar los parámetros de la API: 

// Cambiar el ID de la tabla (si es diferente)
$api_url = "https://n8n-nocodb.kbma6o.easypanel.host/api/v2/tables/TU_ID_TABLA/records";

// Cambiar el ID de la vista (si es diferente)
$viewId = "TU_ID_VISTA";
